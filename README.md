# primeodin

> I build small machines for large questions.

I am interested in the old bargain between wonder and discipline: take a thing apart, learn its invariants, put it back together stronger, and leave clear notes for the next traveler. My work tends to orbit low-level systems, physics-flavored simulation, numerical methods, learning machines, resilient infrastructure, and the strange new craft of steering language models without letting them dissolve into fog.

This profile is the public front door for **primeodin-legacy** — an honest retrospective archive of twenty-one technical chapters, one for each year from 2003 through 2023.

It is not a forged claim of old public activity. The repositories are reconstructed later, with current commits, period-aware constraints, runnable code, and explicit archive notes. I keep the story dressed in frost and iron because that is how hard work feels in memory: long winters of debugging, chalk dust, broken builds, small victories, and the private joy Richard Feynman named so well — *the pleasure of finding things out*.

A rune is just an invariant with poetry on it. Rage is just energy under governance. A kingdom is a system with people depending on it.

## The archive

The arc runs from C89 parsers and hand-managed memory through physics engines, Monte Carlo paths, visual diagrams, utility AI, information theory, neural networks, parallel simulation, early cloud deployment, reinforcement learning, quantum circuits, modernization, self-healing services, attention, prompt craft, and finally a capstone map of the whole road.

Every repository is meant to be small enough to enter, concrete enough to run, and honest enough to learn from.

## What I value

- **Small runnable examples over grand declarations.** A tiny program that fails clearly teaches more than a perfect diagram no one can enter.
- **Period-aware engineering.** Old code should look and feel constrained by its time. Modern code should earn its abstractions.
- **Honest myth.** A metaphor may carry truth, but it must not be used to counterfeit provenance.
- **Resilience before ornament.** The rune that matters is the one that holds when the winter comes.
- **Teaching as proof of understanding.** If I cannot explain it with a clear example, I probably do not own it yet.

## How to read this place

Start anywhere. Clone a repo. Run the smoke script. Break a constant. Change a reward curve. Remove a guard word and watch the allocator complain. Step through attention with a pencil. The point is not to admire the archive from a distance; the point is to put your hands on the machine and feel where the invariants live.

If a repository carries frost and myth in its prose, good. If the code still compiles after the poetry is stripped away, better.
